# Teaching LLM Security Through Containerized Vulnerable Applications

Accompanying repository for *"Teaching LLM Security Through Containerized Vulnerable Applications"*, CSEDU 2026 · Katarzyna Mazur, Maria Curie Skłodowska University, Lublin, Poland.

A Docker-based laboratory framework for teaching ML and LLM application security through hands-on exploitation. Exercises cover both the OWASP Top 10 and the OWASP Top 10 for LLM Applications 2025, and run entirely on a student laptop with no cloud infrastructure or API keys required.

Example exercises: [github.com/katarzynamazur/csedu_2026/tree/main/example_exercises](https://github.com/katarzynamazur/csedu_2026/tree/main/example_exercises)
